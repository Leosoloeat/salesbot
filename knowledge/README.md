# Knowledge Base

ไฟล์ .txt และ .md ในโฟลเดอร์นี้จะถูกโหลดเข้า system prompt อัตโนมัติ
Bot จะใช้ข้อมูลเหล่านี้อ้างอิงเวลาตอบลูกค้า

## วิธีเพิ่ม knowledge
- สร้างไฟล์ .txt ตั้งชื่อตามหัวข้อ เช่น clinic-case-study.txt
- เขียนเป็น plain text ไม่ต้องมี format พิเศษ
- ข้อมูลควรเป็นประสบการณ์จริง ตัวเลขจริง

## ไฟล์แนะนำ
- ads_framework.txt — framework/หลักการยิงแอดที่ใช้ได้ผล
- case_studies.txt — case จริงที่ทำให้ลูกค้า (ไม่ต้องระบุชื่อ)
- faq.txt — คำถามที่ลูกค้าถามบ่อย + คำตอบ
- pricing_detail.txt — รายละเอียดราคาและ package
